Kadane's Algorithm

Maximum Sum Subarray Problem

1. What is Kadane's Algorithm?

Kadane's Algorithm is used to find the maximum sum of a contiguous subarray within a given array of integers.

Instead of checking every possible subarray, it keeps track of the current subarray sum and the maximum sum found so far.

Example

Input:

[-2, 1, -3, 4, -1, 2, 1, -5, 4]

Maximum Sum: 6

Subarray: [4, -1, 2, 1]

2. How does it work?

We maintain two variables:

  • currentSum: Maximum subarray sum ending at the current position.
  • maxSum: Maximum subarray sum found so far.

For every element, we decide whether to:

  • Start a new subarray from the current element.
  • Extend the previous subarray by adding the current element.

The key formula is:

currentSum = Math.max(num, currentSum + num);
maxSum = Math.max(maxSum, currentSum);

🍕 Real-World Example: Circular Pizza

Imagine a circular pizza cut into 5 slices. Each slice has a profit or loss value. Your goal is to select consecutive slices that give you the maximum profit. 

Slices:  A   B   C   D   E
Values:  1   2   3  -2   5

Normal Subarray:

A → B → C 
1 + 2 + 3 = 6

Circular Subarray:

E → A → B → C
5 + 1 + 2 + 3 = 11

Since the pizza is circular, we can wrap around from the last slice to the first slice.

How does our approach find 11?

Total Sum = 9
Minimum Subarray = [-2]

Negated Array:
[-1, -2, -3, 2, -5]

invArrMax = 2 

Circular Max = Total Sum + invArrMax
= 9 - (-2)
= 11

💡 Remember: Instead of finding the best circular portion directly, find the worst portion to exclude. The remaining elements form the maximum circular subarray.

Prefix Sum

Precompute cumulative totals of an array

1. What is Prefix Sum?

Prefix Sum is a technique where we create an additional array that stores the cumulative sum of elements from the beginning of the original array.

In simple terms, each position stores the sum of all elements before it, including itself.

Example

Input:

arr = [2, 4, 1, 5, 3]

output : [2, 6, 7, 12, 15]

2. How does it work?

prefix[0] = 2

prefix[1] = 2 + 4 = 6

prefix[2] = 2 + 4 + 1 = 7

prefix[3] = 2 + 4 + 1 + 5 = 12

prefix[4] = 2 + 4 + 1 + 5 + 3 = 15

3. Why is Prefix Sum useful?

Imagine you have an array: 

arr = [2, 4, 1, 5, 3]

You need to calculate the sum between index 1 and index 3.

Without Prefix Sum:

4 + 1 + 5 = 10

With Prefix Sum:

prefix = [2, 6, 7, 12, 15]
Range Sum(L,R)=prefix[R]-prefix[L-1]
For indices 1 to 3:
        12 - 2 = 10

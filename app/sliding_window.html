Sliding Window

Finding Optimal Contiguous Subarrays & Substrings

1. What is Sliding Window?

The Sliding Window technique is an algorithmic approach used to solve problems involving contiguous (consecutive) elements in an array or string.

It maintains a window representing a specific range of elements. Instead of repeatedly processing every element in that range from scratch, we move the window through the array and reuse the results from the previous window.

The important idea is that we update the current window by adding new elements and removing elements that are no longer part of the window, rather than recalculating everything.

2. When can we use Sliding Window?

Sliding Window is especially useful in these situations:

Pattern 1: Fixed-size Sliding Window

Window size remains constant.

The window contains a fixed number of consecutive elements. As we move forward, one element leaves the window and a new element enters it.

Typical variables: k = window size, windowSum = current window sum.

Use when the problem asks us to calculate something for every consecutive group of a given size.

Examples: Maximum sum of K consecutive elements, average of every K consecutive elements, maximum number of visitors in any K consecutive days.

Pattern 2: Variable-size Sliding Window

Window size changes dynamically.

The window expands or shrinks depending on whether a particular condition is satisfied.

Typical variables: left = starting position, right = ending position.

Use when the problem asks for the longest or shortest contiguous subarray or substring satisfying a condition.

Examples: Longest substring without repeating characters, smallest subarray with sum at least a target (for positive numbers), longest subarray satisfying a given constraint.

3. How does Sliding Window work?

Consider an e-commerce company tracking its daily revenue:

const revenue = [100, 200, 150, 300, 250, 400, 350];
const k = 3;

Step 1: Calculate the first window

100 + 200 + 150 = 450

Step 2: Move the window one position forward

Instead of adding all three elements again:
 Remove 100 (the element leaving the window).
 Add 300 (the new element entering the window). 

450 - 100 + 300 = 650

Step 3: Continue moving the window

650 - 200 + 250 = 700
700 - 150 + 400 = 950
950 - 300 + 350 = 1000

Finally, the maximum revenue is 1000.
The important observation is that we reuse the previous window's calculation to obtain the next window's result.

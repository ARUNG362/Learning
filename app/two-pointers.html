Two Pointers

Finding Pairs & Subarrays in a Sorted Array

1. What is Two Pointers?

The Two Pointers technique is an algorithmic approach that uses two variables (pointers) to track positions in an array. Each pointer moves through the array according to specific conditions to solve a problem efficiently.

The important idea is that we use the positions of two elements to make progress toward a solution, rather than repeatedly checking every possible pair.

2. When can we use Two Pointers?

Two Pointers is especially useful in these situations:

Pattern 1:

Pointers moving toward each other

Typical starting positions: left = 0, right = arr.length - 1.

Use when comparing elements from opposite ends or searching pairs in a sorted array.

Examples: two-sum in a sorted array, palindrome checks, reversing an array.

Pattern 2:

Both pointers move forward

Typical starting positions: read = 0, write = 0.

Use when scanning an array and modifying it in-place, or when processing elements at different speeds.

Examples: remove duplicates from a sorted array, move zeros to the end, merge sorted arrays.

Pattern 3:

Fast and slow pointers

Both pointers move forward but at different rates or according to different conditions.

Examples: detecting cycles in linked lists, finding certain positions in sequences, and some in-place array problems.

🌧️ Real-World Example: Water Trapped Between Buildings

Imagine a row of buildings with different heights. After heavy rainfall, water gets trapped between the taller buildings. Each building's height is represented by an array element. Your goal is to calculate how much water is trapped. 

Buildings:  A   B   C   D   E   F
Heights:    3   0   2   0   4   1

How is water trapped?

Left Maximum  = 3
Right Maximum = 4

Water Level = min(3, 4) = 3

Water Trapped = 3 - Current Height
              = 3 - 0
              = 3 units

Water trapped at each position:

Position:  A   B   C   D   E   F
Height:    3   0   2   0   4   1
Water:     0   3   1   3   0   0

Total Water = 3 + 1 + 3 = 7 units

How does our Two Pointers approach find the answer?

Initialize:

left = 0
right = arr.length - 1

leftMax = 0
rightMax = 0

water = 0

Start with two pointers, one at the beginning and another at the end of the array. 

Heights: [3, 0, 2, 0, 4, 1]
          ↑              ↑
         left           right

Compare the heights at both pointers. If the left height is smaller than or equal to the right height, process the left side. Otherwise, process the right side.

Step 1: Process the left side

height[left] = 3

leftMax = 3

Move left pointer forward.

Step 2: Calculate trapped water

Current Height = 0
leftMax = 3

Water = leftMax - Current Height
      = 3 - 0
      = 3 units

Step 3: Continue moving the pointers

At height 2:

Water = 3 - 2 = 1

At height 0:

Water = 3 - 0 = 3

Final Calculation:

Total Water = 3 + 1 + 3

Output = 7 units

💡 Remember: Instead of calculating the maximum height on both sides for every element separately, maintain leftMax and rightMax while moving two pointers inward. Always process the side with the smaller current boundary because that side determines the water level we can safely calculate.

🌊 1. Understand the Problem

We have vertical lines with different heights. We need to select two lines that can hold the maximum amount of water. 

height = [1, 8, 6, 2, 5, 4, 8, 3, 7]

Our goal: Find the maximum container area.

💡 2. Formula

Width = right - left

Height = min(height[left], height[right])

Area = Width × Height

We use the smaller height because water cannot go above the shorter wall.

🎯 3. Two Pointers Approach

Start one pointer at the beginning and another at the end. 

left = 0
right = height.length - 1

maxArea = 0

Follow these three steps:

1. Calculate the area.

2. Update maxArea.

3. Move the pointer with the smaller height.

🧠 4. Why Move the Smaller Height?

The shorter wall limits how much water the container can hold. 

Left Height  = 1
Right Height = 7

Width = 8

Area = 8 × 1 = 8

If we move the taller wall, the width decreases, but the shorter wall is still the same.

So, move the shorter wall. We might find a taller wall and get a bigger area. 

if (height[left] < height[right]) {
    left++;
} else {
    right--;
}

🔍 5. Simple Dry Run

Input: [1, 8, 6, 2, 5, 4, 8, 3, 7]

Step 1:
left = 0, right = 8
Area = 8 × min(1, 7) = 8
Move left.

Step 2:
left = 1, right = 8
Area = 7 × min(8, 7) = 49
Move right.

Step 3:
left = 1, right = 7
Area = 6 × min(8, 3) = 18
Move right.

Step 4:
left = 1, right = 6
Area = 5 × min(8, 8) = 40
Move either pointer.

Continue until both pointers meet. 

Maximum Area = 49

⚡ 6. Complexity

Time Complexity: O(n)

Space Complexity: O(1)

💡 7. Remember

1. Start pointers at both ends.
2. Calculate the area.
3. Update maximum area.
4. Move the smaller height pointer.
5. Repeat until pointers meet.

Key Point: Always move the shorter wall because it limits the amount of water the container can hold.
